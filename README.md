# Universal Video Downloader

Universal Video Downloader — телеграм-бот для загрузки видео из популярных платформ, с админ-панелью, возможностью настроить обязательные подписки, рекламой и рассылками.

(Создавалось с ИИ)

## Основные возможности

- загрузка видео из TikTok, YouTube, Instagram, Twitter/X, VK и других ссылок
- выбор качества: HD, SD, аудио, скачивание с водяным знаком для TikTok
- поддержка обрезки видео с точностью до миллисекунд
- админ-панель с управлением подписными каналами, рекламой, рассылками и настройками
- хранение данных в SQLite (`data/bot.db`)
- мультиязычный интерфейс (`ru`/`en`)

## Структура проекта

- `main.py` — точка входа, запуск бота, логирование и фоновые задачи
- `config.example.py` — пример конфигурации
- `database.py` — работа с SQLite
- `downloader/` — загрузка видео и определение платформ
- `handlers/` — обработчики пользовательских и админ-команд
- `services/` — очередь, подписки, реклама, рассылки, обрезка
- `i18n.py` — тексты на русском и английском языках

## Быстрый старт

### 1. Клонирование

```powershell
git clone https://github.com/HYBAS22/universal-video-downloader
cd universal-video-downloader
```

### 2. Установка зависимостей

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 3. Установка внешних зависимостей

Проект использует `yt-dlp` и `ffmpeg`.

- `yt-dlp` устанавливается через `pip`.
- `ffmpeg` устанавливается отдельно на систему.

Примеры:

- Windows: скачайте из https://ffmpeg.org/
- Ubuntu/Debian:
  ```bash
  sudo apt update
  sudo apt install ffmpeg
  ```
- macOS:
  ```bash
  brew install ffmpeg
  ```

### 4. Настройка конфигурации

Скопируйте пример и заполните данные:

```powershell
copy config.example.py config.py
```

Откройте `config.py` и установите:

- `BOT_TOKEN` — токен Telegram-бота
- `ADMIN_IDS` — список ID администраторов
- `DOWNLOAD_DIR` — директория для скачанных файлов
- `DB_PATH` — путь к SQLite базе данных
- `LOG_DIR` — директория для логов
- `MAX_FILE_MB` — максимальный размер отправляемых файлов
- `TZ_OFFSET` — смещение временной зоны

### 5. Запуск бота

```powershell
python main.py
```

## Обзор функционала

### Пользовательская часть

- `/start` — запуск бота и выбор языка
- `/help` — помощь по использованию
- `/history` — история загрузок пользователя
- кнопка `Скачать` — ввод ссылки и выбор качества
- кнопка `Обрезать` — запуск траимера видео
- поддержка прямой ссылки в сообщении

### Админ-панель

Команда `/admin`.

В панели доступны:

- статистика по пользователям и загрузкам
- управление каналами подписки
- управление рекламой
- создание и отправка рассылок
- поиск и управление пользователями
- глобальные настройки

### Подписка

Если включена обязательная подписка, бот проверяет наличие подписки пользователя на активные каналы.

### Загрузка видео

- TikTok: приоритетно используется TikWM, TikMate и SSSTik, затем `yt-dlp`
- Все другие платформы скачиваются через `yt-dlp`
- `yt-dlp` сохраняет файл в `DOWNLOAD_DIR`

### Обрезка видео

- `services/trimmer.py` использует `ffmpeg`
- поддерживает миллисекундную точность
- работает с перекодированием (`libx264`, `aac`)

## Настройки и база данных

База данных SQLite создаётся автоматически при запуске.

Таблицы:

- `users` — данные пользователей
- `settings` — глобальные настройки
- `sub_channels` — каналы обязательной подписки
- `ads` — рекламные объявления
- `broadcasts` — рассылки
- `download_history` — история загрузок
- `file_cache` — кэш `file_id`
