# 🎬 Функция обрезки видео (Video Trimming Feature)

## 📋 Описание

Добавлена функция обрезки видео, которая позволяет пользователям обрезать скачанные видео по указанному времени.

## 🎯 Возможности

- **Обрезка видео** — пользователь может выбрать время начала и конца
- **Поддержка форматов времени** — MM:SS (00:15) или просто секунды (15)
- **Быстрая обработка** — используется копирование потоков без перекодирования (копирование кодека)
- **Обработка через очередь** — интеграция с существующей системой очереди задач
- **Двуязычный интерфейс** — поддержка русского и английского языков

## 📦 Добавленные файлы и изменения

### 1. **services/trimmer.py** (новый файл)
   - Основной модуль для обрезки видео
   - Функция `trim_video()` использует ffmpeg через subprocess
   - Поддерживает валидацию времени и обработку ошибок
   - Очищает временные файлы при ошибках

### 2. **handlers/user.py** (изменён)
   - Добавлены новые состояния FSM: `trim_ask_start`, `trim_ask_end`
   - Кнопка "✂️ Обрезать видео" в меню выбора качества
   - Обработчик `cb_trim()` для инициирования процесса обрезки
   - Обработчики `process_trim_start()` и `process_trim_end()` для ввода времени
   - Функция `_parse_time()` для парсинга времени в формате MM:SS или секунды
   - Функция `_do_trim()` для выполнения обрезки в очереди
   - Поддержка кэширования и загрузки видео перед обрезкой

### 3. **i18n.py** (изменён)
   - Новые строки для русского языка:
     - `btn_trim` — кнопка обрезки
     - `trim_ask_start` — запрос времени начала
     - `trim_ask_end` — запрос времени окончания
     - `trim_format_err` — ошибка формата
     - `trim_logic_err` — ошибка логики (конец < начало)
     - `trim_loading` — сообщение о загрузке
     - `trim_fail` — ошибка обрезки
     - `trim_done` — сообщение об успехе
   
   - Аналогичные строки для английского языка

### 4. **requirements.txt** (изменён)
   - Добавлен комментарий о необходимости ffmpeg

## 🔧 Требования

- **ffmpeg** — должен быть установлен и доступен в PATH
  - Linux: `apt-get install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Windows: скачать с https://ffmpeg.org/download.html

## 📖 Использование

1. Пользователь отправляет ссылку на видео
2. Выбирает "✂️ Обрезать видео" вместо выбора качества
3. Отправляет время начала обрезки (MM:SS или просто секунды)
4. Отправляет время окончания обрезки (MM:SS или просто секунды)
5. Система скачивает видео и обрезает его
6. Обрезанное видео отправляется пользователю

## 🔄 Процесс выполнения

```
User sends video link
    ↓
System detects platform
    ↓
User selects "Trim Video"
    ↓
User enters start time (MM:SS or seconds)
    ↓
User enters end time (MM:SS or seconds)
    ↓
Task added to queue
    ↓
Worker downloads video
    ↓
FFmpeg trims video (copy codec - no re-encoding)
    ↓
Trimmed video sent to user
    ↓
Cleanup temporary files
```

## ⚙️ Технические детали

- **Копирование потоков**: используется `-c:v copy -c:a copy` для быстрой обработки без перекодирования
- **Timeout**: 120 секунд на операцию обрезки
- **Валидация**: 
  - Время начала должно быть ≥ 0
  - Время окончания должно быть > времени начала
  - Минимальная длительность обрезки: 0.1 сек
- **Лимиты**: обрезанное видео также должно быть ≤ 50 МБ (лимит Telegram)

## 🐛 Обработка ошибок

- Если видео не найдено в кэше, система скачивает его заново
- При ошибке обрезки показывается сообщение об ошибке с причиной
- Временные файлы автоматически очищаются в finally блоке
- Timeout обработки — 300 секунд (5 минут)
